# AsterIDE V2

A **new** and **refined** version of **AsterIDE**, rewritten for a cleaner, quicker UX.

---

**AsterIDE** has faced a few issues that are difficult to tackle,
and instead of going at them headon, we have decided to redefine **AsterIDE**
as a genuine IDE from the near ground up, doing this allows for improvements and changes
in a much cleaner and more organized way, the structure as of v1.6.5 is really sloppy,
and needs a more organized codebase, we are splitting them up into actual proper crates
the way **Crane** would, instead of having `crates/{crate}/src`, we are doing it as `asteride_{crate}/src`.

This might seem like it would cause issues with the codebase right now but we plan on making this structure
really clean and easy to expand on, probably..

As of right now, **AsterIDE** remains as Version 1.6.5 Stable. Version 2.0.0 will release at an unestimated time.
